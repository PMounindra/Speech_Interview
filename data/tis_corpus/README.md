===========================================================

 ## Project: Trustworthy Intent in Speech (TIS) ##

===========================================================

  Welcome to the TIS Corpora Dataset! This dataset is made available as open-access to facilitate research and development in the field of voice perception, speech processing, and related areas.

This repository contains materials (including Python codebase, WAV and CSV data) linked to the upcoming paper publication "Human voices communicating trustworthy intent: A demographically diverse speech audio dataset" by Constantina Maltezou-Papastylianou, Reinhold Scherer and Silke Paulmann.

========================
 1. REPOSITORY CONTENTS
========================

    AUDIO FILES: Located in Speech_WAV_Files/. Includes 1,152 speech recordings in WAV file format of untrained speakers (i.e. not actors) talking with a (1) trustworthy intent, (2) neutral intent (i.e. their natural speaking voice).

    SPEAKER DEMOGRAPHICS: Speaker_demographics.csv contains demographic information for each speaker.

    ACOUSTIC FEATURES: Speech_dataset_characteristics.csv provides extracted acoustic features for each audio file.

    ANALYSIS CODE: Found in Python_SourceCode_SpeechDB/. Includes Python scripts for preprocessing, descriptives, classification analysis and visualisation.

-----------
 NOTE: More details can be found in our upcoming paper publication linked to this repository, titled "Human voices communicating trustworthy intent: A demographically diverse speech audio dataset".
-----------


====================
 2. GETTING STARTED
====================

    2.1. DOWNLOAD THE REPOSITORY: Use the OSF download button to get the files.
    2.2. INSTALL DEPENDENCIES: Ensure you have Python and necessary libraries from requirements.txt (in the project directory run in the terminal: pip install -r requirements.txt)
    2.3. EXPLORE AND ANALYSE: Load the CSV files and audio data, then run the Python script "main.py" to begin the analyses.
