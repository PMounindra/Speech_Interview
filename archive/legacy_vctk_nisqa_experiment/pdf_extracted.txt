1. Executive Summary
InterviewSense is a speech-analysis research pipeline designed to convert spoken audio into quantitative acoustic
descriptors and use those descriptors to predict a human-rated speech quality score. The current laptop experiment
is deliberately smaller than a full-scale research pipeline: it processes up to 10,000 VCTK recordings and 2,000
NISQA recordings and reuses saved feature checkpoints so that repeated notebook runs are fast.
The central supervised target is the NISQA Mean Opinion Score (MOS). NISQA provides human ratings of
perceived speech quality on a 1–5 scale. Therefore, the experimentally validated task is speech-quality
regression. It is not yet a validated interview-fluency, communication-skill, or candidate-performance score.
The project has two feature representations. The primary representation is a compact handcrafted acoustic
representation consisting of 48 numeric features covering timing, silence and pauses, energy, zero-crossing rate,
pitch, spectral characteristics, and 13 MFCCs with mean and standard deviation statistics. The comparison
representation is eGeMAPSv02, an established speech-feature set. Both representations are evaluated using the
same XGBoost regression family so that the main experimental difference is the feature representation.
The completed run produced 12,000 extracted feature rows: 10,000 VCTK and 2,000 NISQA. Correct NISQA
metadata matching recovered 1,036 valid MOS labels from the 2,000 NISQA feature rows. The primary model
achieved a test MAE of 0.5912, RMSE of 0.7240, and R² of 0.4797. The eGeMAPS comparison achieved MAE
0.5731, RMSE 0.7301, and R² 0.4709.

Do not present the current MOS predictor as an interview communication score. The model has been trained and
evaluated against NISQA MOS. To make a scientifically valid claim about interview fluency or communication quality,
the project needs a human-rated interview/communication dataset whose labels directly represent that target.
2. Problem Statement and Motivation
Speech contains information at several levels. Some information is linguistic—what a person says—while other
information is paralinguistic or acoustic—how the speech sounds. Timing, pauses, energy, pitch, spectral distribution
and cepstral characteristics can all be measured without requiring the system to understand the entire semantic
content of an utterance.
InterviewSense uses this acoustic route because it is computationally practical on a laptop and provides
interpretable measurements. The idea is to create a repeatable numerical representation of speech and then learn a
mapping from that representation to a human rating.
The research question in the present experiment can therefore be stated as:
Can a compact handcrafted acoustic representation predict human-rated speech quality, and how does its
performance compare with an established speech representation such as eGeMAPS?

5. Acoustic Feature Extraction
The project's main representation is handcrafted rather than a learned embedding. The extractor uses librosa to
convert each waveform into a fixed-length numerical vector. Fixed-length vectors are important because XGBoost
expects tabular input where each row represents one recording and each column represents a feature.

Whisper in the current run and uses CPU-parallel acoustic extraction. It also saves feature checkpoints every 250
recordings.

The successful metadata file was the NISQA corpus CSV. It contains the degraded filename and MOS. The

10. Numerical Preprocessing
Before modelling, the feature matrices are cleaned. Positive and negative infinity values are replaced with NaN.
Missing values are then filled using medians calculated from the training set.
The same training medians are applied to validation and test data. This is important because computing imputation
statistics from the full dataset could leak information from the validation/test sets into training.
11. Primary Model — XGBoost Regression
The primary model is XGBRegressor. XGBoost is a gradient-boosted decision-tree method. Instead of training one
tree, it builds a sequence of trees where each new tree attempts to correct errors made by the previous ensemble.
For this project, the model receives a 48-dimensional acoustic vector and outputs one continuous number: the
predicted NISQA MOS.

MAE intuition
An MAE of 0.5912 means that, on average, the model's predicted MOS differs from the human MOS by about 0.59
MOS points on the evaluated test set.
RMSE intuition
RMSE of 0.7240 is larger than MAE because RMSE gives more weight to larger mistakes. It is therefore useful for
detecting whether a model occasionally makes substantially wrong predictions.
R² intuition
R² = 0.4797 means the model explains approximately 48% of the variance in the held-out target values relative to a
mean-only reference. It does not mean the model is 47.97% accurate.

15. Five-Fold Group Cross-Validation
A single train/test split can be sensitive to which recordings happen to fall into each partition. The notebook therefore
performs five-fold GroupKFold evaluation on the primary representation.

trained from scratch for that fold and evaluated on its held-out fold. The notebook records MAE, RMSE and R² for

16. Feature Importance and Interpretability
The notebook extracts XGBoost feature_importances_ values and sorts the 48 handcrafted features from most to
least important. This creates a feature-importance table that can be saved as primary_feature_importance.csv.
Feature importance should be interpreted as model usage, not as proof of causation. If a feature has high
importance, it means the fitted model relied strongly on it when making predictions; it does not prove that changing
that acoustic property would necessarily change the human MOS.
The feature families themselves provide a useful interpretability layer: timing features describe speech/silence
organization, pitch features describe fundamental-frequency behavior, energy features describe amplitude, spectral
features describe frequency distribution, and MFCC statistics describe spectral-envelope characteristics.
17. Prediction Diagnostics
The notebook also produces a true-versus-predicted MOS scatter plot. The x-axis contains the true NISQA MOS
values and the y-axis contains model predictions. A diagonal reference line represents perfect prediction.
Points close to the diagonal indicate good predictions. Systematic compression toward the center can reveal a
model that predicts extreme ratings conservatively. Outliers far from the diagonal identify recordings where acoustic
information was insufficient or the learned relationship did not generalize well.

A dataset can be useful for feature engineering without being suitable as the supervised target dataset. VCTK
provides a large amount of multi-speaker speech, but the final experiment needs a numeric human-rated target.
NISQA provides that target through MOS.
Combining VCTK and NISQA directly into one supervised target without a common label definition would be
methodologically incorrect. Therefore, VCTK is retained as a feature-development resource while NISQA supplies

22. What the Model Is Actually Learning
The model is not directly learning the meaning of an interview answer. It is learning statistical relationships between
measurable acoustic patterns and perceived speech quality ratings in the NISQA corpus.
For example, a combination of timing, energy, pitch and spectral characteristics may correlate with higher or lower
perceived quality. XGBoost can represent nonlinear interactions among these variables. It does not require a linear
assumption such as 'more pitch variation always means better speech.'
Because the target is subjective MOS, there will naturally be irreducible variation. Different listeners can rate the
same speech differently, and acoustic features do not capture every factor that influences perception.

27. Faculty / Viva Questions You Should Be Ready For
What is the exact target?
NISQA MOS, a human-rated perceived speech-quality score from 1 to 5.
Is this an interview communication score?
No. The current experiment validates speech-quality regression. A human-rated interview dataset is required for that
claim.
Why XGBoost?
The input is structured tabular acoustic features, and XGBoost can model nonlinear relationships efficiently on CPU.
Why not classify MOS?
MOS is naturally continuous, so regression preserves more information than forcing it into discrete classes.
Why use eGeMAPS?
It is an established speech-feature representation and provides an external feature-level baseline.
Why use the same XGBoost model for comparison?
It keeps the regressor approximately constant so the feature representation is the main experimental difference.
Why do you need cross-validation?
A single split can be noisy. Five-fold GroupKFold shows how performance varies across several held-out folds.
What is MAE?
Mean absolute error: the average absolute difference between predicted and true MOS.
What does R² = 0.4797 mean?
The model explains about 48% of the variance in the evaluated target relative to a mean-only baseline; it is not 48%
accuracy.
Why did the notebook become fast after the first run?
The expensive acoustic features were saved as checkpoints and loaded instead of recomputed.
Why only 1,036 labelled samples?
Only those NISQA recordings had a successful filename-to-MOS metadata match among the 2,000 processed
recordings.
Why not use all VCTK for training?
VCTK does not provide the same compatible human-rated MOS target used by NISQA.

30. Conclusion
InterviewSense currently provides a complete, reproducible acoustic speech-quality baseline. The system starts with
speech recordings, extracts a compact 48-dimensional acoustic representation, repairs genuine NISQA MOS labels,
trains an XGBoost regression model, compares that representation against eGeMAPS, and evaluates stability
through five-fold group-aware cross-validation.
The completed experiment demonstrates that the handcrafted representation contains useful information for
predicting perceived speech quality. Its test performance is competitive with the eGeMAPS comparison under the
same XGBoost modelling family: the handcrafted representation has slightly better RMSE and R², while eGeMAPS
has slightly better MAE.
The central scientific limitation is also clear: NISQA MOS is a speech-quality label, not an interview communication
label. Consequently, the current project should be presented as the acoustic baseline and methodological
foundation for InterviewSense. The next major research step is to obtain human-rated interview data and
retrain/evaluate the system against the actual communication objectives.
Bottom line: the current pipeline is not a fake or placeholder experiment. It has a real human-rated target, a
reproducible feature-extraction process, a primary regression model, an established external feature comparison, and
cross-validation. What remains is to connect that validated acoustic machinery to a genuinely interview-specific target.
